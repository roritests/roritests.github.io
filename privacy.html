Privacy policy

Last updated: 16 October 2026

The Rori Tests uploader is a private tool used only by the owner of the YouTube channel Rori Tests (@roritests).

What it accesses

With the owner's permission it uses the YouTube Data API to upload videos to the owner's own channel and to read that channel's basic information (name and ID) to confirm the right channel is used.

What it does not do

It does not access, collect, store or share data about any other person. It does not sell data, show ads or use data for any other purpose. Access tokens are stored only as private settings of the owner's own automation and are never published.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
